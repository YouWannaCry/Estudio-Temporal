Las tres piezas

Workflow
Orquesta decisiones. Debe ser determinista. No hace HTTP, SQL ni usa el reloj del sistema.
Activity
Hace trabajo externo: REST, base de datos, correo. Puede reintentarse.
Worker
Proceso Java que escucha una Task Queue y ejecuta Workflows y Activities.
Traducción desde Spring

Un Workflow se parece a un servicio orquestador, pero tiene reglas de replay. Las Activities sí pueden delegar en repositorios y clientes HTTP.
